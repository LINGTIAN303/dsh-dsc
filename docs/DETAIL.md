# DeepSeek App 面板

复刻 DeepSeek 对话界面的插件：左侧栏一个入口图标，中央一屏全屏对话面板。

## 界面

- 左侧栏「DeepSeek」图标，点开进入面板。
- 面板是竖屏的对话布局：侧栏会话列表、欢迎语、消息流、底部输入框。
- 深度思考与智能搜索是两个开关，状态作用于之后的每一轮对话。

**对齐基准是官网页版（chat.deepseek.com），不是 DeepSeek App。** 侧栏 261px、消息列 752px、输入框 776px 等数值全部取自网页版实测。App 版（iOS / Android）的界面移植还没开始——`< 768px` 下的抽屉侧栏是网页版的响应式适配，不等于 App 版。

## 能力

- 深度思考：开启后模型在推理中自行联网搜索、打开网页、页内查找，界面按官方样式显示折叠的思考过程与用时。
- 智能搜索：模型按提问自行搜索网页并附引用；引用角标可点开右侧来源面板。
- 阅读链接：消息里带 URL 时自动抓取网页并结合上下文作答。
- 文件输入：拖拽、粘贴或点附件按钮上传 PDF、Word、PowerPoint 与图片；需要看图的文档按版面解析，纯文本类按文本解析。
- 语音输入：点麦克风录音，结束后自动转写成文字填入输入框。
- 朗读回答：每条回答下方的「朗读」按钮把正文合成语音播放。
- 内容安全：默认开启服务端基础风控；命中时按官方行为丢弃该轮回答并提示。

## 密钥

三种来源，按顺序取第一个可用的：

1. 面板设置里填写的 API Key（存进本机的 DSH 凭据，不进浏览器）。
2. 已登录的 DeepSeek 账号。
3. 环境变量 `DEEPSEEK_API_KEY`。

浏览器只与 Host 的 `/api/deepseek-chat` 通信，密钥不会出现在页面里。设置里的「校验」用一次免费的 `GET /models` 确认 Key 有效。

## 会话存在哪

会话历史写在 Host 的 `~/.dsh/plugins/dsh-deepseek-chat/sessions.json`，换浏览器或清缓存都不会丢。

## 计费

除模型 Token 外，联网搜索、网页抓取、文件解析、语音识别与语音合成按 DeepSeek 官方工具价格单独计费。

## 限制

- 只有 `deepseek-flash`（V4.1-Flash）支持这套服务端工具，其他模型不接受这些参数。
- 朗读与语音输入依赖浏览器录音与音频播放权限；没有麦克风权限时语音输入不可用。
- 开启安全校验后，服务端会在回答结束后再做一次审核，因此末尾可能多等一会儿。
